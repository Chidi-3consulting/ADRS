# 3Consulting mark

**Primary mark: the plain 3C.** "3C" in a confident serif (Fraunces) inside a double ring, in 3Consulting orange **#ff914d**. It uses the same two-ring language as the ASI mark, so the parent company and its product read as one family. The repository root holds a copy as `3consulting-3c.png`.

**Alternative: the 3C seal.** The same mark, with the company's pillars lettered in the band (*Data protection · Cybersecurity* over the top, *AI assurance* below), like the stamp on a certificate. Kept for certificates, reports and anywhere a "seal of assurance" fits. The repository root holds a copy as `3consulting-seal.png`.

**Lockups.** Both pair the mark with the existing typewriter-style "3Consulting" wordmark (IBM Plex Mono) and the tagline *Build trust in the digital economy*.

| File | Use |
|---|---|
| `icon.svg` / `icon.png` (512) / `icon-1024.png` / `icon-white.svg` | **Primary mark:** website, social avatar, app and browser icon, documents |
| `lockup.svg` / `lockup.png` | **Primary lockup** (plain 3C + wordmark + tagline): letterheads, e-mail signatures, website header |
| `seal.svg` / `seal.png` / `seal-white.svg` / `seal-on-dark.png` | Alternative seal, from about 64 pixels up |
