# SafeData brand assets

This folder contains the product branding package for SafeData by 3Consulting.

## Core brand decisions

- Product name: SafeData by 3Consulting
- Tagline: “Keep what you must. Release what you should.”
- Secondary line: “We govern your data without hoarding it.”
- Brand symbol: Guardians mark (two figures + shield beneath the Lifecycle Ring, reinterpreted as a halo)
- Main colours:
  - Ink navy: #111827
  - 3Consulting orange: #ff914d
  - Warm off-white: #f7f4ee
  - Teal / amber / red for status use only

## Files in this package

- `safedata-lifecycle-ring.svg` — primary mark
- `safedata-lifecycle-ring-dark.svg` — dark background variant
- `safedata-wordmark-lockup.svg` — lockup with wordmark and tagline
- `safedata-wordmark-lockup-dark.svg` — dark lockup
- `safedata-icon.svg` — app/icon mark: two guardian figures under a halo arc, shielding a record (current primary mark, light surfaces)
- `safedata-icon-dark.svg` — the guardians mark for dark surfaces
- `safedata-mark-on-dark.svg` — transparent-background guardians mark for in-app chrome (sidebar, login header) that already sits on a dark or orange field
- `favicon/` — generated `.ico` set (16–256px) rasterized from `safedata-icon.svg`
- `safedata-hero-slide.png` — slide-ready file used in decks (not yet supplied)
- `safedata-logo-1024.png` — export-ready PNG for presentations and docs (not yet supplied)

## Design intent

The guardians mark keeps the original Lifecycle Ring equity — the open arc and its orange record-dot — but reframes the ring as a halo arcing over two simplified guardian figures who shield a record (checkmarked shield) between them. The gap in the halo, marked by the orange dot, still reads as the point of lawful release; the figures make the "who" of data governance explicit — people actively safeguarding data, not just an abstract timer.

Use the orange dot as the anchor signal for records, retention countdowns and compliance actions. The primary wordmark (`safedata-wordmark-lockup.svg`) is clean, plain-language and calm, matching the “Calm Authority” positioning; its icon glyph should be updated to the guardians mark when next revised.
