Phase 1 — Data Retention Lifecycle: Five Mandatory Stages
📥
STAGE 01
Collection
Data is captured with a defined purpose and lawful basis documented at source before any processing begins.
Record reference created in system
Legal basis documented (GDPR Art. 6)
Category assigned (GDPR / NDPR)
Retention end date auto-calculated
Audit log entry: record_created
DPO notified if created by Data Owner
⚙️
STAGE 02
Active Use
Data is actively used for its stated purpose. Access controls are enforced and the audit trail is active throughout.
Status: Active in the system
Role-based access enforced
File attachments can be added
Cron monitors daily for approaching end date
Legal hold can be applied at any time
Consent withdrawal can be logged (B1)
📅
STAGE 03
Retention
Purpose fulfilled. Data is retained only as long as legally required. The automated engine enforces the schedule.
30-day alert window begins
Status changed to: due_review
Owner notified (or DPO if no owner)
Audit log: record_flagged_review
Consent-based: 30-day countdown starts
14-day escalation to Admin (B7)
🔍
STAGE 04
Review
DPO or Admin reviews the flagged record. Four possible outcomes: dispose, archive, extend via legal hold, or escalate.
DPO / Admin reviews record details
Decision: Dispose / Archive / Hold
Dual approval required if sensitive (B5)
Auto-disposal if no action after due date
Quarterly schedule review (quarterly)
Recalculation queue if category changed
✅
STAGE 05
Disposal
Secure deletion, anonymisation, or archiving is executed. Full evidence trail logged. DPO notified of confirmation.
Delete: soft-delete + deleted_at timestamp
Anonymise: PII fields nulled, status=disposed
Archive: status=disposed, data preserved
Audit log: record_disposed_{method}
DPO confirmation email sent
Evidence available for NITDA / ICO audit
Phase 2 — Automated Retention Engine: Daily Cron Job (01:00 AM WAT)
⚡
Daily Automated Engine — retention_cron.php
Runs via cPanel Cron Job at 01:00 AM Africa/Lagos timezone. Nine independent steps. CLI-only (browser access blocked).
01
Bootstrap & Configuration
Load config, establish PDO with timezone fix (+01:00), read system settings: review_alert_days, escalation_days, consent_disposal_days.
🔧 System Init
02
Flag Records for Review
Find date-based records where retention_end_date ≤ today + 30 days and status = 'active'. Update to 'due_review'. Set review_flagged_at timestamp. Skip consent_withdrawal categories.
📋 Date-Based Only
03
Consent-Based Disposal (B1)
Find consent_withdrawal records where consent_withdrawn_at ≤ today − 30 days and status ≠ 'disposed'. Execute disposal per category method. GDPR Art. 17 compliant.
👤 Consent Trigger
04
Auto-Dispose Overdue Records
Find due_review records past their retention_end_date. Skip: legal_hold=1, requires_dual_approval=1. Execute: delete / anonymise / archive per category. DB transaction: record + audit_log atomic.
🗑️ Auto-Disposal
05
14-Day Escalation (B7)
Find due_review records where review_flagged_at ≤ today − 14 days and escalation_sent_at IS NULL. Set escalation_sent_at. Send urgent summary email to ALL Admin users.
🚨 Admin Alert
06
DSAR Deadline Alerts (C1)
Find DSARs due in exactly 5 days → send alert to assigned user + DPOs. Find overdue DSARs → send urgent escalation. GDPR Art. 12: 30-day response required.
📨 DSAR Monitor
07
Batched Owner Notifications (N1)
Group review notifications by category owner. Send one email per owner with all their flagged records. If owner_id IS NULL: notify all DPOs with "no owner assigned" warning badge.
🔔 N1 Fallback
08
Retry Failed Notifications
Fetch notifications where status IN ('failed','pending') AND attempts < 3 AND created_at ≥ 48 hours ago. Re-attempt send. Update status and attempts count.
🔄 Retry Logic
09
Completion & Error Digest
Log completion summary to cron.log: records flagged, disposed (by method), escalated, notified, retried, duration. If any errors: send error digest email to all Admins.
📊 Summary Log
Phase 3 — Key Decision Gates in the Disposal Workflow
🔒
DECISION GATE 1
Legal Hold Check
Before any disposal action (automated or manual), the system checks: legal_hold = 1
legal_hold = 1
BLOCKED. No disposal executed. Record stays in current state.
legal_hold = 0
Proceed to Dual Approval Gate.
🔐
DECISION GATE 2
Dual Approval (B5)
System checks: requires_dual_approval = 1 on the record's category.
SENSITIVE
Step 1: User A requests. Step 2: Different User B confirms. Cron skips auto-disposal.
STANDARD
Any Admin or DPO can dispose directly. Cron auto-disposes if overdue.
⚖️
DECISION GATE 3
Disposal Method
System reads: disposal_method from the record's data category.
🗑️ Delete: soft-delete + deleted_at. Status = disposed.
👤 Anonymise: NULL PII fields. Record skeleton retained for statistical use.
📦 Archive: Status = disposed. All data preserved for legal hold/audit.
Phase 4 — Role Responsibilities Across the Lifecycle
System Administrator
Full Access
▸Manage all users, roles, and system settings
▸Create, edit, delete data categories
▸Create, edit, reassign data records (any category)
▸Approve standard disposal directly (single-step)
▸Step 2 approver for dual-approval disposal (B5)
▸Set and lift legal holds
▸View and export full audit log
▸Receive 14-day escalation alerts (B7)
▸Trigger bulk CSV import (B8)
▸Configure SMTP and system settings
▸Export DB backup from admin panel
Data Protection Officer (DPO)
Compliance Lead
▸Create and edit data categories
▸Review and action flagged records
▸Log consent withdrawals (B1)
▸Review recalculations queue (B2)
▸Approve standard disposal (single-step)
▸Step 2 approver for sensitive disposal (B5)
▸Set and lift legal holds
▸Manage DSAR requests and deadlines (C1)
▸Export audit log + NDPR annual report
▸Receive all compliance notifications
▸Run quarterly retention schedule review
Data Owner
Operational Role
▸Create records in their own categories only (B4)
▸Collection date locked to today (no backdating)
▸Cannot edit or delete records after creation
▸View own category records in read-only mode
▸Upload file attachments to own records (S8)
▸Download attachments for own records
▸Receive review notifications for own categories
▸View limited dashboard (own categories)
▸Update own profile and password
▸Cannot dispose, hold, or view audit log
▸Cannot access DSAR module
