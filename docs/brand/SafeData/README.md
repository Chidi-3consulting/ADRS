# SafeData brand assets

This folder contains the product branding package for SafeData by 3Consulting.

## Core brand decisions

- Product name: SafeData by 3Consulting
- Tagline: “Keep what you must. Release what you should.”
- Secondary line: “We govern your data without hoarding it.”
- Brand symbol: Lifecycle Ring
- Main colours:
  - Ink navy: #111827
  - 3Consulting orange: #ff914d
  - Warm off-white: #f7f4ee
  - Teal / amber / red for status use only

## Files in this package

- `safedata-lifecycle-ring.svg` — primary mark
- `safedata-lifecycle-ring-dark.svg` — dark background variant
- `safedata-wordmark-lockup.svg` — lockup with wordmark and tagline
- `safedata-wordmark-lockup-dark.svg` — dark lockup
- `safedata-icon.svg` — app/icon mark
- `safedata-icon-dark.svg` — app/icon mark for dark surfaces
- `safedata-hero-slide.png` — slide-ready file used in decks
- `safedata-logo-1024.png` — export-ready PNG for presentations and docs

## Design intent

The Lifecycle Ring is an open timer arc ending in a data-record orange dot. The gap represents lawful release. This symbol mirrors the product promise: govern retention, prove compliance and release data when the legal or policy clock ends.

Use the orange dot as the anchor signal for records, retention countdowns and compliance actions. The primary wordmark is clean, plain-language and calm, matching the “Calm Authority” positioning.
